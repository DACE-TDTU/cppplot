# Glossary of Terms – Control Engineering Textbook (CppPlot)

This glossary lists and explains important terms and concepts from the textbook, using simple English. Terms are sorted alphabetically for easy reference.

---

**Actuator**: A device that turns a control signal into physical action (like a motor or valve).

**Agentic Control**: Control using smart agents (AI) that can make decisions and adapt.

**Bode Plot**: A graph showing how a system responds to different frequencies (magnitude and phase).

**Closed-Loop (Feedback) System**: A system that uses its output to adjust its input, reducing error.

**Compensator (Lead/Lag)**: A controller that changes system response, often to improve stability or speed.

**Controller**: The part of a system that decides what action to take to reach the goal.

**Control System**: A group of devices working together to keep something (like temperature or speed) at a desired value.

**Damping Ratio (ζ)**: A number that shows how much a system resists oscillation.

**Dead Zone**: A range where a system does not respond to small input changes.

**Digital Control**: Using computers or microcontrollers to control a system with digital signals.

**Digital Twin**: A virtual copy of a real system used for simulation and testing.

**Disturbance**: An unwanted change or influence that affects the system.

**Error Signal**: The difference between the desired value (setpoint) and the actual value.

**Feedback**: Sending part of the output back to the input to improve control.

**Frequency Response**: How a system reacts to signals of different frequencies.

**Gain**: How much a system amplifies or reduces a signal.

**Impulse Response**: The output when the input is a very short pulse.

**Laplace Transform**: A math tool to change equations from the time domain to the frequency domain.

**Natural Frequency (ωn)**: The frequency at which a system naturally wants to oscillate.

**Nyquist Plot**: A graph used to check if a feedback system is stable.

**Observer**: A method to estimate values inside a system that cannot be measured directly.

**Open-Loop System**: A system that does not use feedback; it cannot correct itself.

**Optimal Control**: A way to control a system to get the best performance according to some rule.

**PID Controller**: A common controller using Proportional, Integral, and Derivative actions.

**Plant**: The part of the system being controlled (like a motor, furnace, or robot).

**Pole**: A value that affects how a system responds over time; related to stability.

**Reference (Setpoint)**: The target value the system tries to reach.

**Reinforcement Learning**: A type of machine learning where an agent learns by trial and error.

**Robust Control**: Control that works well even if the system model is not perfect.

**Root Locus**: A plot showing how the system's poles move as a parameter (like gain) changes.

**Sensor**: A device that measures a physical quantity (like temperature or speed).

**Sliding Mode Control (SMC)**: A control method for systems with uncertainties, using switching logic.

**State Feedback**: Using all the internal variables (states) of a system to design the controller.

**State-Space Model**: A way to describe a system using variables for all its internal states.

**Step Response**: The output when the input suddenly changes and stays at a new value.

**System Identification**: Finding a math model for a system by using real data.

**Time Constant (τ)**: How quickly a system responds to changes; lower τ means faster response.

**Transfer Function**: A math formula that relates input to output in the frequency domain.

**Zero**: A value that makes the system output zero for a certain input frequency.
